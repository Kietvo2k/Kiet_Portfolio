# Vo Tuan Kiet Portfolio

Static one-page bilingual portfolio for Vo Tuan Kiet.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a simple static server:

```powershell
python -m http.server 8080
```

Then visit `http://127.0.0.1:8080`.

## Update content

- Main layout and fallback Vietnamese copy: `index.html`
- Translated Vietnamese/English copy and toggles: `script.js`
- Visual design, responsive layout, light/dark theme: `styles.css`
- Hero/achievement visuals are CSS-based; no personal photo is required.

## Deploy

This site has no build step. Deploy the whole folder to GitHub Pages, Vercel, Netlify, or Cloudflare Pages as a static site.
